About Nearby Stars

This 3D visualization shows 28,800 nearby stars within 100 parsecs (about 326 light-years), using real data from the SIMBAD astronomical database. It also simulates how the stars move over time using real stellar-motion data.

Help

  • Left mouse drag: Rotate the scene.
  • Right mouse drag: Pan the scene.
  • Mouse wheel: Zoom in or out.
  • Ctrl + click: View information about a star.
  • Play: Start the simulation of future star movement.
  • Reset: Return the simulation to its starting point.
